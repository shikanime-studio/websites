# hikari

Cosplay photoshoot commission planner — request a shoot, agree on place
and time, receive the photos, and track where each commission stands.
Inspired by [ImaCoCoS](https://omiomi79.github.io/imacocos/).

Stack: TanStack Start on Cloudflare Workers, D1 (drizzle), R2 photo
storage, better-auth Google sign-in. Keyless Google Maps embeds and
Calendar template links — no Google SDKs.
